# 分发版检查与已知边界

此包为独立分发版本，不含Vina、Python、数据库结构或商业软件授权。
首次调用请读 first-use.md。安装skill本身不等于安装运行环境，也不保证宿主支持安装后自动提醒。

## 本版已补上的问题

| 原有问题 | 补丁 |
|---|---|
| 固定D盘路径，别人电脑不能直接用 | PATH发现、用户选定路径、限定目录扫描、本地配置文件 |
| 只认Vina 1.2.7，其他可用版本也被拒绝 | 基线版本加实际CLI功能检查；不同版本警告并要求真实输入验证 |
| 已有PDBQT仍要求装Meeko | dock/prepare/validate/repair四类按需检查 |
| Python、pip、Meeko来自不同环境 | 绑定当前解释器，记录模块版本和位置，跨目录CLI提示 |
| 能import但实际不可用 | RDKit 3D/InChI/RMSD、Meeko配体转换、OpenMM CPU功能试验 |
| 找不到工具时无下一步 | 检查报告逐项提供修复建议和官方来源 |
| 随意扫描全部硬盘 | 先问路径或指定扫描范围，深度/目录数限制，跳过重解析点 |
| 覆盖既有环境报告或配置 | 要求新报告名；不自动安装、改PATH或替换已有环境 |

## 别人仍可能遇到的情况

1. 该包是智能体工作流与辅助脚本，不是全自动点击式对接软件。具体结构准备、网格和化学状态仍需依据实际输入判断。
2. Windows是已测试平台。Linux/macOS的Python检查逻辑可以适配，但没有在这些系统实测；不能宣称跨平台全部通过。
3. 软件源、网络代理、conda求解、DLL与CPU架构会变化。建议在独立环境安装，检查之后保存实际版本清单；没有一套固定版本号适合所有平台。
4. Meeko的实际受体模板、金属、非标准残基和宏环支持需要用真实输入试验。环境检查通过不代表所有结构都能处理。
5. AD4需要匹配的AutoGrid映射；本版检查Vina maps接口，不替用户验收每个映射文件或自动安装AutoGrid。PyMOL是可选项，授权与显示环境另行处理。
6. PowerShell策略可能拦截脚本，可直接运行Python检查器；不要为使用skill放宽全局执行策略。没有Python时必须先安装或提供真实解释器。
7. 第三方程序对中文、空格和长路径的支持不一致。必要时复制到短路径计算，并保留原始文件、哈希和路径对应关系。
8. RMSD辅助脚本要求正确的原始参考SDF和显式原子映射；它不会自动解决共价化学或被优化过的参考坐标。柔性受体输出需要另行适配，不能直接套用纯配体原子集合校验。
9. 小规模功能检查不能替代真实受体重对接。不同版本的随机数、搜索和模板可能产生不同结果，必须保留版本与运行输入。
10. 重新整理结果时，旧best_poses文件可能仍在磁盘；以当前summary中status=ok且明确链接的姿态为准，不通过glob把残留文件纳入分析。优先使用新的运行目录。

## 测试范围

执行真实本机Vina CLI检查、Python/准备功能检查，以及模拟缺失工具、较新功能完整版本、旧版缺功能、错误引擎和子进程超时分支。目录扫描测试限定在指定文件夹，未执行发现的候选文件。
这些测试不代表在其他人的操作系统或所有软件版本上实测通过。分发包不包含开发者真实路径配置、运行日志或用户数据。
